SCM Task 1.2

DESCRIPTION
This project is a part of our Source Code Management(SCM) continuous evaluation(Lab number-13 to 22).

INSTALLATION STEPS
Clone the repository using git clone https://github.com/bhanvi786/SCM-project.git, navigate to the project directory with cd SCM-project, 
ensure .gitignore is properly set up to exclude unnecessary files, and open the project in your preferred code editor.

USAGE
Track changes using git status, add files to the staging area with git add ., commit changes using git commit -m "Your commit message", and 
push to GitHub with git push origin Hello.
